
# Курсовая работа №3
____
## Тема 
В этой работе реализована программа, которая собирает данные о самолетах в воздушном пространстве нескольких стран.
Эти данные сохраняет в базу данных и делает несколько аналитических методов по фильтрации записей БД,
____
## Реализация
 - Создание классов для работы с API. 
 - Создание класса для работы с информацией о самолетах.
 - Создание класса для работы с БД.
____
## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/Sergey-Shinkevich/Country_Airplanes_With_Database.git] (https://github.com/Sergey-Shinkevich/Country_Airplanes_With_Database.git)
2. Установите зависимости через Poetry:
   ```bash
   poetry install
3. Запуск осуществляется с помощью модуля main.py в случае созданной базы данных, иначе нужно предварительно запустить create_db.py
____
## Использованные API сервисы
- Для получения координат стран: Open Street Map https://nominatim.openstreetmap.org/
- Для получения данных о воздушных судах: Open Sky Network https://opensky.network.org/ 
____
## Ограничения
Обработка антимеридиана: текущая реализация не поддерживает ограничивающие рамки (bounding boxes), пересекающие 180-й меридиан (антимеридиан). Запросы, охватывающие области, разделенные этой линией, могут приводить к ошибкам API. Учитывая масштаб проекта, данная функциональность исключена из текущей версии.
